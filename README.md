# Patrones Estructurales (GoF)

Repositorio de la exposición de **patrones de diseño estructurales** en Java.

## Aportes

| Carpeta | Tema |
|---|---|
| [`persona3-flyweight/`](persona3-flyweight/README.md) | Introducción, Bridge, Flyweight y conclusiones |

Cada integrante agrega su carpeta con su parte de la exposición. Los patrones
estructurales (Adapter, Bridge, Composite, Decorator, Facade, Flyweight y Proxy)
explican cómo componer clases y objetos para formar estructuras más grandes y
flexibles, manteniendo bajo el acoplamiento.

## Requisitos

- Java 17 o superior
- Maven 3.9 o superior

Cada ejemplo es un proyecto Maven independiente dentro de su carpeta.
